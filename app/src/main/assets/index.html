HTML TO APK/AAB Detaylı Kullanım Kılavuzu

1. Üretilen Proje Özellikleri & Seçenekler

  • • Otomatik Paket Kimliği : Uygulama adına göre package ID otomatik biçimlendirilir
  • • Açılış Ekranı & Özel Logo : İstediğiniz renk ve logoyla profesyonel splash screen
  • • Yuvarlatılmış İkon : Squircle formatında otomatik kırpılmış ana ekran ikon seti
  • • Arka Planda Çalışma & Boot : Foreground Service ve Cihaz Açılış Desteği
  • • Çevrimdışı Mod & İzinler : İnternet kopma uyarısı, Depolama, Bildirim, Alarm ve GPS

2. Yöntem A: GitHub Actions ile Online Derleme (Önerilen)

  1. İndirdiğiniz ZIP dosyasını bilgisayarınızda bir klasöre çıkartın.
  2. GitHub hesabınızda yeni ve boş bir depo (Repository) oluşturun (README, .gitignore veya LICENSE eklemeyin).
  3. ZIP'ten çıkan tüm dosyaları ve klasörleri doğrudan bu repoya yükleyin (Commit edin).
  4. Reponuzda üst menüden Actions sekmesine tıklayın.
  5. Derleme sürecinin tamamlanmasını bekleyin (Yeşil tik olduğunda işlem başarılıdır).
  6. İlgili workflow detay sayfasına girerek alt kısımdaki app-debug-apk ve app-debug-aab çıktılarını bilgisayarınıza indirin!

3. Yöntem B: Android Studio ile Bilgisayarınızda Yerel Derleme

  1. Bilgisayarınızda Android Studio programını açın.
  2. Karşılama ekranından Open seçeneğine tıklayarak ZIP'ten çıkardığınız proje ana klasörünü seçin.
  3. Proje açıldığında sağ üst köşede çıkacak olan Gradle senkronizasyonunun (Sync Project with Gradle Files) bitmesini bekleyin.
  4. Üst menüden Build > Build Bundle(s) / APK(s) > Build APK(s) yolunu izleyin.
  5. Derleme tamamlandığında sağ altta çıkan bildirim penceresinden locate yazısına tıklayarak üretilen APK dosyanızı doğrudan alın!
